# Sakana Restaurant Website

A static website for Sakana, a Japanese restaurant located in Madrid, Spain. The website showcases the restaurant's menu and services.

## Features

- Menu/Carta display
- Online reservation system
- Photo gallery of the restaurant
- Contact information and location

## Structure

- `index.html` - Homepage with restaurant overview
- `carta.html` - Complete menu with images
- `reservation.html` - Table booking system
- `gallery.html` - Photo gallery of interior and exterior
- `contact.html` - Contact information and map
